# Black Walnut

Black Walnut is a fresh, responsive, minimal Business WordPress theme. The page templates for the front page, an About page, a Menu, Testimonials and Contact page as well as the beautiful, minimal two-column blog layout make Black Walnut the perfect little theme for small businesses like cafés, restaurants, yoga schools or freelancer businesses.

By [Elmastudio](https://www.elmastudio.de/en/).

- **Version:** 1.0.9
- **Theme page:** https://www.elmastudio.de/en/wordpress-themes/blackwalnut/
- **Documentation:** [English](https://www.elmastudio.de/en/docs/blackwalnut/) / [German](https://www.elmastudio.de/doks/blackwalnut/)

## Installation

Download this repository as a ZIP and upload it in **Appearance → Themes → Add New → Upload Theme**, or clone it into your WordPress installation:

```
cd wp-content/themes
git clone https://github.com/elmastudio/blackwalnut.git
```

## Status
